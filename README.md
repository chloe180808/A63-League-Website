# A63 League Website

A website for the A63 League, a 9-team amateur football league with over 100 registered players.

I'm developing the site to provide a central place for players to view league standings, fixtures, results and statistics, with further features planned as the project develops.

## Current Development

The website currently includes:

- a Season 7 homepage
- the nine-team league table interface
- a knockout-stage interface
- responsive styling for different screen sizes
- navigation placeholders for future league, fantasy and statistics features

The league data is currently represented with placeholder values while I develop the JavaScript logic that will calculate and display standings from fixture results.

## Planned Features

- Calculate league standings automatically from fixture results
- Display matches played, wins, draws, losses, goals and points
- Update the table when fixture results change
- Display fixtures and results
- Player and team statistics
- Fantasy football functionality
- Integration with persistent league data

## Development

This is an ongoing independent project for a real amateur football league.

I'm using the project to develop my web development skills while working from real requirements and league data. The current focus is moving from a static interface to a data-driven league table using JavaScript.

The project is being developed incrementally as I learn new web technologies and determine the requirements for future league and fantasy features.
